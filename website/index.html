Native C++20 game-engine foundation

Build a game workflow you can understand and extend.

Forge Engine is an early, local-first native editor and runtime. Start with a real versioned scene, a software wireframe preview, and a separate runtime - with current limits stated plainly.

Get started Build and download

An honest alpha

No verified public release asset is available yet. Build from source using the Windows instructions or check the live GitHub Releases page.
Implemented

Native editor and runtime

Separate C++20 programs share a core library. The current window layer targets Win32 and Linux/X11.

Partial

Editable scene foundation

Create a project, inspect a scene list, move a selection, save version-2 JSON, and run a basic wireframe session.

Planned

Production rendering and import

GPU rendering, lighting, materials, model import, and executable export are future milestones, not current features.

Start with a real project

  1. Configure, build, and run the native applications with the Windows build guide.
  2. Open the included starter project or create one in Forge Hub.
  3. Follow the first-scene tutorial and run the separate runtime.

Local by default

The current editor does not require an account, contact a model provider, or send project data to a service. Pre-existing account and AI scaffolding is not exposed as an alpha feature. Read the privacy notes.

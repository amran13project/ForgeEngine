Next milestones

Ship reliability before breadth.

The roadmap prioritizes a trustworthy scene workflow and platform evidence over placeholder feature counts.

P0 · Validate the native baseline

  • Windows x64 Debug and Release CI with CTest.
  • Fix any runner, workflow, test, or website validation failures.
  • Test editor/runtime startup, shutdown, and sample save/reopen on a Windows desktop.

P1 · Dependable editing

  • Project folder picker and explicit project selection.
  • Dirty tracking, save prompts, safer save replacement, and undo/redo.
  • Editable inspector and validated translation controls.
  • Hierarchy parenting after transform semantics are tested.

P2 · Creation workflow

  • Evaluate and test a maintained GPU renderer.
  • Add one model-import path, asset errors, and reimport.
  • Add real material/light rendering and a measured sample.
  • Separate content packaging from executable export.

P3 · Runtime and optional systems

Evaluate physics, audio, animation, scripting, and plugin integrations as separate testable milestones. Profiling must use actual runtime measurements.

Later · AI

Planned AI requires explicit user consent, local/cloud choice, project permission boundaries, safe secret handling, cancellation, and privacy tests. It is not currently available.

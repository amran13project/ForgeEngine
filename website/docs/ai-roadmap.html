Planned later phase

AI is not available in this alpha.

Pre-existing local orchestration/provider scaffolding remains in the repository for future evaluation. The current editor does not expose AI, contact a provider, or send project content externally.

Required before implementation

  • Optional local and cloud provider choices, clearly distinguished.
  • Explicit consent before any project data leaves the machine.
  • No project-code, asset, log, prompt, or credential upload by default.
  • OS credential storage for any future keys; never store them in a project or logs.
  • Scoped file/editor permissions, visible plans, confirmation for destructive actions, and cancellation.
  • Privacy, offline, permission, cancellation, and prompt-injection tests.

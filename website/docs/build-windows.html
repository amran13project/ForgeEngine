Windows x64

Configure, build, and test.

Use CMake and an installed C++20 Visual Studio toolchain. No dependency download is required by the CMake build.

Prerequisites

  • Windows 10/11 x64.
  • CMake 3.20 or newer.
  • Visual Studio 2022 C++ desktop workload and Windows SDK.

Build and test

cmake -S . -B build -A x64 -DFORGE_BUILD_TESTS=ON
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure

GitHub Actions uses the same configure/build/test commands on a Windows-hosted runner for both Debug and Release.

Run the editor and sample

.\build\Release\ForgeEngine.exe
.\build\Release\ForgeRuntime.exe .\samples\ProfessionalStarter3D

Both applications need an interactive desktop session. A CI compile/test pass does not verify window rendering or mouse interaction.

Optional app icon

cmake -S . -B build -A x64 -DFORGE_APP_ICON="assets/branding/forge-engine.ico"

Omit the option until the project owner supplies the final icon. See icon integration instructions.

Troubleshooting

If the generator is missing, install the Visual Studio C++ workload. The current release workflow has no custom icon dependency. The legacy portable builder can download a large compiler archive and is not the recommended validation path.

Build instructions do not claim a completed local build.

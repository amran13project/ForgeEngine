Documentation

Build, open, and understand Forge Engine.

The documentation describes the current source, not a future product promise.

Requirements and build

Windows development requires Windows 10/11 x64, CMake 3.20+, Visual Studio 2022 C++ desktop tools and the Windows SDK. Linux development requires a C++20 compiler, CMake 3.20+, and X11 development libraries.

cmake -S . -B build -A x64 -DFORGE_BUILD_TESTS=ON
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure

See the complete Windows build guide and quick start for runtime commands and keyboard controls.

Project and scene format

A project has a ForgeProject.json manifest and a project-relative default scene path. Scene version 2 stores entities, IDs, names, types, transforms, visibility, and lock state in JSON. Selection is editor-only and is not persisted. Unsupported versions, malformed fields, duplicate IDs, and non-finite transforms are rejected without replacing the in-memory scene.

There is no version-1 migration yet. Back up project files before changing scene data manually.

Editor tour and boundaries

  • Forge Hub creates projects and discovers existing projects under the default ForgeProjects folder.
  • The scene panel selects entities; keyboard arrows and W/S translate the selection. Inspector values are currently read-only.
  • The viewport is a software wireframe preview. It is not a GPU renderer and does not provide lighting or materials.
  • The Assets panel indexes and classifies files; it does not import models or textures.
  • The Package action copies project content; it does not produce a standalone executable.

Troubleshooting

If a project cannot open, verify that its manifest exists and its default scene uses supported version 2. Windows GUI startup needs an interactive desktop. Linux runtime needs an active X11 display. For current feature boundaries see Features and for known issues see FAQ and troubleshooting.

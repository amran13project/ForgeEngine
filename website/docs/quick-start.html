First project

Build and run the starter scene.

No account or internet connection is required by the editor.

Build

Follow the Windows build guide, then run the binaries from build/Release.

Open or create a project

Run ForgeEngine. Create a local 3D starter project, or copy samples/ProfessionalStarter3D into the default ForgeProjects directory and choose Open Project. Current Open Project behavior chooses the first discovered project.

Edit and save

Select an entity in the scene panel. Arrow keys move it along the preview ground plane; W/S move vertically. Inspector values are read-only. Ctrl+S writes version-2 scene JSON. Selection itself is not persisted.

Play and stop

F5 toggles the current basic play loop. Stopping restores an in-memory snapshot of the scene. The separate runtime can be started with ForgeRuntime.exe <project-directory>.

Current boundary: the viewport is a software wireframe preview; Package copies project files but does not build an executable.

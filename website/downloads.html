Windows x64 source build

Install CMake 3.20+, Visual Studio 2022 C++ desktop tools, and the Windows SDK. Then run:

cmake -S . -B build -A x64 -DFORGE_BUILD_TESTS=ON
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure

See build details. The alpha release workflow will package the editor, runtime, quick-start guide, notices, and sample after tag-triggered Windows tests pass.

Minimum runtime expectations

Windows x64 needs an interactive desktop and a compatible Windows runtime. Linux builds need an interactive X11 session and the system X11 libraries. A discrete GPU is not required for the current software wireframe preview.

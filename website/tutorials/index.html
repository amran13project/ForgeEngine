Lesson 01 · Beginner · Windows x64

Create, save, and run your first scene.

This lesson uses the actual project and scene flow currently available. It does not require art assets or an online account.

Prerequisites

Build ForgeEngine and ForgeRuntime using the documentation. The starter sample is in samples/ProfessionalStarter3D.

1. Open the sample

Copy samples/ProfessionalStarter3D into the default ForgeProjects directory, launch ForgeEngine, then choose Open Project. The current project manager discovers this folder and opens its first valid project.

2. Select and move an entity

Choose Cube in the scene list. The center area draws a software wireframe preview; the inspector shows read-only transform values. Use the arrow keys to translate across the ground plane and W/S to move vertically.

Use + Cube to add a mesh, or Delete to remove the selected unlocked entity. There is no undo/redo yet.

3. Save and reopen

Press Ctrl+S or select Save. The current scene is written as version-2 JSON to the project's default scene path. Close the editor normally and launch it again to verify the saved project. Failed or unsupported scene loads are reported and do not silently replace the current scene.

4. Run the scene

Press F5 to enter play mode and F5 again to stop. The editor restores its scene snapshot when play stops. To run the separate runtime, use:

.\build\Release\ForgeRuntime.exe .\samples\ProfessionalStarter3D

The runtime requires an interactive desktop. Its renderer is still a wireframe preview; no executable export or GPU renderer is included.

Expected limitations: project selection, scene editing, rendering, and packaging remain early-stage. Consult the feature status before relying on an unsupported workflow.

Lesson verified against current source behavior; graphical runtime still requires platform testing.

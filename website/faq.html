FAQ and troubleshooting

Known limits and useful checks.

Does Forge Engine have a GPU renderer?

No. The current viewport and runtime draw a software-projected wireframe preview. Lighting, materials, and depth-tested rendering are planned.

Does Package build a game executable?

No. It copies project content and writes a manifest. It must not be treated as a standalone export.

Why does Open Project choose a project automatically?

The editor currently discovers projects only in the default ForgeProjects folder and opens the first valid result. A folder picker and explicit selection are planned.

What scene format is supported?

Version 2 JSON only. The loader rejects malformed data and leaves the current in-memory scene intact on failure. Version 1 migration is not implemented.

Do I need an account or internet connection?

No account is required. The active editor does not make network requests. Existing account/AI scaffolding is not an enabled user-facing feature.

How do I report a build problem?

Include the full CMake configure/build/CTest output, the compiler and Windows version, and whether the issue reproduces with the included sample. Remove secrets and personal paths before sharing logs.

See Windows build troubleshooting and current feature status.

Current capabilities

Working foundations, clearly bounded.

Forge Engine is an early native C++20 project. The status labels below refer to tested workflows, not just the presence of source files.

Implemented baseline

Projects and scenes

Project manifest and folder creation; version-2 scene JSON; entity IDs, transforms, visibility, locks; validation before scene replacement.

Partial

Native editor and runtime

Win32 and X11 window paths, scene list, keyboard translation, wireframe preview, basic play loop and separate runtime.

Partial

Assets and diagnostics

File indexing/classification and structural project checks. No importer, reimport queue, dependency graph, or full validation.

Partial

Packaging

Copies project files into a payload directory and writes a manifest. It does not compile the game or create a release export.

Planned

Renderer and import

GPU rendering, depth, lighting, materials, 2D, glTF import, and asset upload.

Planned

Creator tools

Editable inspector, hierarchy parenting, undo/redo, dirty-state prompts, mature runtime physics, audio, animation, and scripting.

Planned

AI

No AI UI or provider is available. A privacy-first design is recorded in the AI roadmap.

For implementation details see the documentation and roadmap.

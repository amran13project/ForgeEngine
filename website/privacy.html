Privacy by default

Your project stays on your machine.

The current editor is local-first. No analytics, telemetry, crash upload, account sign-in, model calls, or project upload is enabled by this application.

Local files

Forge reads and writes the selected local project, its scene, and generated package/cache files. The editor currently uses the default ForgeProjects directory for project discovery.

Network

The user-facing alpha editor has no network-service feature. GitHub Actions and GitHub Pages workflows run only in GitHub's hosted environment under repository settings and workflow permissions; they do not transmit the user's local project content during normal application use.

Future AI work

AI is planned only. Any future provider integration must disclose local versus cloud processing and require explicit consent before transmitting project data. See the AI roadmap.

Contact and source

Review the public source repository for current implementation and issue reporting. Do not include credentials or private project content in a public report.

No hidden telemetry is claimed or included.

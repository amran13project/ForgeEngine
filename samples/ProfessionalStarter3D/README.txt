Forge Engine 3.2.0 native sample project.

The sample contains a versioned project manifest and a small scene with a camera,
one wireframe mesh, and a directional-light entity. The current software
renderer previews mesh entities as wireframes; lighting and material rendering
are not implemented.

To use it in the editor, copy this folder into the default ForgeProjects folder
shown by Forge Hub, then choose Open Project. To launch the standalone runtime:

  ForgeRuntime <path-to-ProfessionalStarter3D>

The runtime requires a graphical Windows desktop or Linux/X11 session.

# Using Forge Engine Professional 3.0

1. Open `Build-ForgeEngine-Windows.cmd` once.
2. Open `Run-ForgeEngine.cmd`.
3. Create a Forge account.
4. Create a project.
5. Edit the scene and press Play.
6. Use Forge AI, Doctor, Profiler and Publish Center when needed.

Windows uses a portable LLVM-MinGW toolchain inside this folder. No system CMake installation is required for the creator build.

# Try Forge Engine

1. Build the project using the [Windows build guide](docs/build-windows.md).
2. Run `build\Release\ForgeEngine.exe`.
3. Create a local project or copy `samples\ProfessionalStarter3D` into the default `ForgeProjects` directory and choose Open Project.
4. Select an entity and move it with the arrow keys or W/S.
5. Save with Ctrl+S and press F5 to start/stop the basic play mode.
6. Run `build\Release\ForgeRuntime.exe samples\ProfessionalStarter3D` to open the separate runtime.

The editor is an early alpha: it currently shows a software wireframe preview and does not include GPU rendering, model import, undo/redo, or game executable export. No account or internet connection is required.
